# NICU Work for Android

English-only, on-device neonatal ward preparation calculator.

This project is being populated with the Android application and its tested preparation engine. It supports rooms and patients, prescribed-dose preparation, microdrip and vial totals, and an English whole-ward PDF report.

Calculations reproduce the supplied ward method. They do not prescribe doses or establish drug stability. Product-specific settings must be reviewed against an approved ward protocol.

Patient records are stored on the device and are never committed to this repository.
